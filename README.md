## Featured Projects

### Parchhain

A privacy-first offline AI journal and memory app for Android.

The goal is to help users write, reflect, and revisit personal memories without sending their private data to the cloud.

**Focus areas:**  
Flutter, local-first architecture, offline AI, personal data ownership, journaling UX.

---

### Peernest

A collaboration platform for high school students to share projects, research ideas, resources, and learning opportunities.

The goal is to help students discover collaborators and build stronger academic/project profiles.

**Focus areas:**  
Student collaboration, project discovery, profiles, communities, web app development.

---

### Temp Clipboard

A temporary clipboard tool for quick text sharing with automatic expiry.

Useful for moving short text between devices without keeping it stored permanently.

**Focus areas:**  
Firebase, temporary storage, simple UX, utility-based product design.

---

### Finger Cursor Controller

A computer-vision experiment that uses hand gestures and voice commands to control cursor movement.

**Focus areas:**  
Python, computer vision, gesture recognition, accessibility experiments.

---

### prvnydvr.com

My personal portfolio and project archive for documenting my work, experiments, case studies, and learning journey.

**Focus areas:**  
Next.js, TypeScript, Tailwind CSS, portfolio design, technical writing.
